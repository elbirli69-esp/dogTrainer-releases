# 🐕 DogTrainer

**App de adiestramiento canino con IA sensorial.**

Usa los sensores del movil (acelerometro, giroscopio, microfono, GPS) para detectar tirones de correa, ladridos, estres y reactividad durante los paseos con tu perro.

## 📥 Descargar

👉 **[Descargar ultima version (APK)](https://github.com/elbirli69-esp/dogTrainer-releases/releases/latest)**

### Como instalar
1. Descarga el archivo .apk desde el enlace de arriba
2. En tu Android: **Ajustes → Seguridad → Permitir fuentes desconocidas**
3. Abre el APK descargado e instala
4. Concede permisos de ubicacion, microfono y actividad fisica cuando te lo pida

### Requisitos
- Android 8.0 o superior
- GPS y sensores de movimiento

## 🎯 Que hace la app

- 🎯 Detecta tirones de correa en tiempo real
- 🚦 Semaforo de reactividad (Verde/Amarillo/Rojo)
- 🔊 Deteccion de ladridos, grunidos y jadeo
- 🤫 Coaching adaptativo que no sobrecarga al usuario
- 📍 Mapa en pantalla completa durante el paseo
- 📊 Resumen detallado al terminar el paseo
- 🎯 Misiones diarias y gamificacion
- 📔 Diario de disparadores (que causa los tirones)
- 💚 Analisis de bienestar canino
- 🔬 Modo diagnostico para exportar datos

## ⚠️ Nota

Version beta para pruebas de campo. Los umbrales de deteccion se estan ajustando con datos reales.
